# Derma : An AI Based Skin Disease Screening System
By Ruengsit Matachaiyasit & Teerapat Sittichottithikun

Derma is an AI-based system designed to screen and classify skin diseases from photographic images. Using deep learning and image classification, the system analyzes uploaded skin images and provides a preliminary assessment to support early awareness and encourage appropriate medical consultation.

# Disclaimer
⚠️ This result is an AI-based preliminary screening and is NOT a medical diagnosis. The model may produce incorrect results. Please consult a qualified healthcare professional for proper evaluation.
